星图影像下载器 1.8.0 · Windows x64

软件更新：右上角「检查更新」只查指定 GitHub 仓库的公开稳定版。选择「下载并校验」后，等待 SHA-256 校验通过，再关闭软件、打开保存文件夹并手动运行安装包。不会自动安装。

登录账号：首次启动或未登录时，每次打开都会自动弹出顶部「登录账号」。所有账号信息都在同一窗口填写，左侧只选择数据。登录成功后默认在当前 Windows 用户下加密保存，下次打开自动恢复。公开数据可选择「暂不登录，选择数据」。
账号管理：各平台可「退出并删除」；也可「清除全部登录信息」。密码、Secret 和令牌不回填到网页，不进入普通配置或下载记录。动态验证码不保存，需要时补填当前验证码。更多规则见同目录 ACCOUNTS.md。
桌面图标：桌面与开始菜单快捷方式使用指定的 globe-orbit 图标，新安装默认创建桌面快捷方式。
联合下载：选择主来源后，在「附带下载」勾选 GEDI 或其他来源。只画或导入一次区域，所有来源共用 UTC 起止日期。检索后在各来源页签分别选择结果与文件；确认整个计划后开始。静态产品仅共用区域；年度、季度和汇总产品不能当作某日单景。
GEDI 跟随主影像：选择「跟随本次主 GeoTIFF」，可在检索结果下方选择具体参考文件。主影像完成后读取其实际网格，导出 GEDI 参数；可附带采样。所选参考失败时会提示，不换用另一影像。
每个来源单独显示进度与失败，已校验完成的文件保留；共同输出含研究区 SHP、联合记录及来源子目录。更多用法见同目录 BATCH.md。

完整城市：在研究区域「按城市」选择省级行政区和城市，使用完整行政边界；北京等直辖市包含下辖县区，可另存为整城 SHP。内置目录来自 2024 年公开边界，已转为 WGS84；也可导入自己的城市 SHP。
逐月下载：Sentinel-2 三条区域路线可选择开始、结束月份。每月先下载并校验全部已选整景，再只读本地文件拼接整月影像，最后按完整城市边界裁剪，保存一份城市主影像。整景、整月中间影像及最终成果分别保留，各阶段可继续。各月单独选择产品和优先级，只用本月来源；无匹配月份明确记录。计划显示整景体积和临时空间；完整波段不等于完整 SAFE，Sentinel Hub 使用整景导出。根目录保留完整 SHP 和月度记录。详情见同目录 CITY_MONTHLY.md。
取消与继续：规划、检索、下载及继续任务均可从地图外任务栏取消。未完成入口可继续下载，也可取消并移除；保留已校验文件和有效缓存。消息提示不遮挡取消操作。在线底图失败时显示本地行政边界，提供重试，城市选择和下载仍可使用。

地图选片：默认仅显示已选完整产品，同一卫星同次过境合并真实范围；可切换全部候选、逐产品及采集日期，地图筛选不改变下载选择。黄色边界为研究区；影像总览定位全幅，放大地图展开查看。点击交叠范围选择具体产品和其他日期，与列表同步。精简推荐清理完整重复覆盖，保留独有边缘；可手动加选补云日期，分配范围可单独开启。
跨日期拼接：默认一份研究区影像，云量较低优先，可改日期较新或手动排列；已选影像可补齐云与 NoData，实际日期见像元来源图。时间序列选项逐产品导出。
删除边界：地图删除按钮可清除已导入 SHP、多地块编辑或未完成绘制，同时清除检索、选择和计划。

使用「数据来源与下载方式」选择区域 GeoTIFF、整瓦片或原始数据文件。
无需个人密钥：Sentinel-2 L1C 原始 JP2、Sentinel-2 L2A 区域裁剪或整瓦片 COG、Sentinel-2 L3 季度镶嵌、Landsat C2 L2、Sentinel-1 GRD 原始文件、Sentinel-3 SEN3、Sentinel-5P L2 大气 NetCDF、DEM 裁剪或整瓦片。
Sentinel-2 L2A 区域研究包：默认保存 B02/B03/B04/B08/B05/B06/B07/B8A/B11/B12 主影像、未掩膜备份、SCL 和逐像元来源。云区和负反射率保留在备份中；主影像全云时仍保存整组文件。SCL 0 为真实类别，255 才是覆盖外；云掩膜保留雪类 11。20 米波段对齐到 10 米不增加源细节。详情见同目录 S2_RESEARCH.md。
官方 S3 区域拼接：检索和下载均需 CDSE S3 密钥。先用官方 XML 修正边界、采集时间与云量，再校验原始像元并拼接。研究模式每产品保留 14 个完整原件缓存（十波段、SCL、两份 XML、清单）；首次较大，可复用，不消耗 Sentinel Hub 额度。选定原件不等于完整 SAFE。
Sentinel Hub 边缘覆盖：本次真实接缝发现部分官方有值位置在服务中为无数据。要求同版官方像元完整覆盖时使用官方 S3 区域入口。
完整 Sentinel-2 SAFE：在区域选项点击「下载完整 Sentinel-2 SAFE」，保留研究区及日期，切换官方 L2A 原始完整产品及 OData；重新检索所需产品。它保留 12 个波段、云雪、AOT/WVP、XML 和角度资料。研究包仍是区域派生数据。
Sentinel-2 L2A 整瓦片：单选一个瓦片，在列表中勾选源波段、分类、真彩和元数据。验证源 SHA-256；保留像元、原网格和缩放，不裁剪或构建 SAFE。
Sentinel-2 L3 季度镶嵌：选择与日期范围重叠的季度，可选 4 个 10 米波段（B02/B03/B04/B08）。保留 Source Cooperative 镜像 DN 和整瓦片；有效值乘 0.0001 得反射率，-32768 为无数据。TIFF 本身没有缩放。镜像索引缺失或不匹配时不提供下载。
ESA WorldCover：免密钥，日期与 2020 或 2021 年度区间重叠时匹配。选择 Sentinel-2 年度合成（RGBNIR / NDVI / SWIR）、Sentinel-1 年度 Gamma0 合成，或土地覆盖分类图。研究区仅用于查找整瓦片；无该年份或图层不替换。保留源像元、缩放、偏移、NoData 和分类调色板。
MODIS Collection 6.1：五类免个人密钥（NDVI/EVI、红光/近红外反射率、昼夜 LST、LAI/FPAR、NBAR）。按 UTC 标称日与研究区查找 MODLAND 整瓦片。可选原始 HDF4、目录所列 XML 和分层 COG，不裁剪。校验源长度、版本、MD5；NDVI/EVI 物理值乘 0.0001，不乘源 TIFF 标签中的 10000。详细缩放及质量层注意事项见下载记录。
Sentinel-1 IW SLC：东南亚历史公开存档（2014-10-06 至 2024-04-04，并非连续或全球覆盖）。按采集起始 UTC 日和研究区查找，保存原始 SAFE ZIP，保留复数 I/Q、子波束和极化，不裁剪。免个人密钥。逐段锁定源版本，核对 ASF 全文件 MD5、ZIP CRC 和 SAFE 清单；不换成 GRD 或 RTC。
SLC 试用：研究区 123.70,-8.145,123.74,-8.10，起止日期都填 2014-11-01；VV 原始 ZIP 约 0.97 GB。
Sentinel-1 RTC：按区域导出所选极化（VV/VH/HH/HV）的线性 γ⁰ Float32 GeoTIFF，不转 dB。选择所选景共有的极化。程序尝试获取临时读取授权，服务拒绝时不改用其他来源。这不是 GRD 原始测量文件。
Sentinel-3：选择 SLSTR、OLCI、SYNERGY 或 SRAL 产品；可选原始成员，或验证清单和全部文件后保存完整 .SEN3 目录。日期和研究区仅用于筛选，不裁剪。
Sentinel-5P：选择大气变量和 OFFL / NRTI / RPRO，目录按 UTC 与研究区筛选；下载原始条带，不裁剪。
NASA GEDI：选择 L1B 波形、L2A 高度、L2B 冠层结构、L3 汇总栅格、L4A 足迹生物量、L4B 汇总生物量或 L4C 结构复杂度，并明确选择当前或历史版本。检索免费且无需登录；下载使用独立的 NASA Earthdata 账号或 User Token。Copernicus 凭据不能用于 GEDI。
GEDI 连接：在顶部「登录账号」的 NASA Earthdata 页签载入 User Token，也可填写 Earthdata 用户名密码。首次使用可能需在「所选 NASA 产品说明」打开的 Earthdata Search 中完成 LP DAAC / ORNL DAAC 授权。登录信息默认加密保存在本机，下次打开自动恢复；请只在本机界面填写。
GEDI 输出：可仅保留原始文件，或同时导出所选参数的足迹 CSV/GeoJSON、均值 GeoTIFF 和观测数量 GeoTIFF。完整波形/剖面写入表格数组。各级数据可用 shot_id 关联；shot_number 请按文本导入。
GEDI 对齐：选择之前下载的 GeoTIFF，完整采用它的坐标系、像元网格、行列数和范围；可勾选在足迹表格中附带该影像的像元值。约 25 米足迹是离散观测，细网格的空隙保留 NoData；1 km 栅格最近邻对齐不会增加观测分辨率。高程的垂直基准须另行核对。
GEDI 日期：足迹主要覆盖约 51.6°S–51.6°N；2023 年 3 月至 2024 年 4 月暂停观测。L3/L4B 日期匹配整个汇总期，不能拆分为某一天。详细参数、质量与验证状态见同目录 GEDI.md。
Sentinel Hub 裁剪：使用同一 OAuth 客户端的 Client ID 和 Client Secret。请仅在本机界面填写，已公开的 Secret 应撤销并重新创建。
官方原始产品：检索无需凭据；按下载计划使用 CDSE OData 账号/令牌或 CDSE S3 密钥。

原始文件可在同一个产品中勾选多个，保持源网格，不等同于完整产品包。目录可查不代表当前账号可下载；确认计划会显示所需凭据。
输出不写入程序目录。卸载不会删除已经下载的影像。
Microsoft Edge WebView2 Runtime 用来显示桌面界面。

所有数据按来源、产品依次处理，当前产品完整性校验后再处理下一个。原始数据保留来源格式；区域结果保存可直接分析的影像与配套记录。
失败或取消后点击重试／继续下载。重启后可从未完成下载恢复原选择；已校验原件和区块可复用，已完成产品核验后跳过。账号密钥更新后使用当前登录。
