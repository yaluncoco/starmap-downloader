# 官方完整 ZIP 下载

软件默认选择「Sentinel-2 L2A · 官方完整 ZIP（与网页一致）」。画出研究区或导入边界、选择 UTC 日期后检索，勾选需要的精确产品，再点击「下载选中完整 ZIP」。下载使用已保存的 CDSE 账号；检索无需登录。Sentinel Hub Client ID 和 Secret 用于另一条区域裁剪路线。

默认每个产品保存一个同名文件，例如：

    S2A_MSIL2A_20240610T030531_N0510_R075_T50TMK_20240610T081949.SAFE.zip

研究区只筛选相交的产品，ZIP 保存完整源范围。保留全部原始波段、质量与大气图层、产品和瓦片元数据，以及实际产品附带的辅助文件。地图显示几个源产品，就按选择保存几个 ZIP；地图上的内部处理区块不决定 ZIP 数量。

使用 Copernicus Browser 的官方产品编号和整包下载入口。传输显示实际接收字节、速度与预计剩余时间；目录成员体积只是估算，实际 ZIP 长度由下载服务确定。下载完成后检查产品身份、全部 ZIP 文件 CRC 和 SAFE 清单声明的成员长度及散列，记录本地 ZIP SHA-256。目录产品校验值不直接视为动态打包 ZIP 的完整散列；完整性校验也不等于影像科学质量评价。

失败或取消后可以继续同一任务。支持服务提供强对象版本标识时的前缀续传；版本或长度变化时拒绝混拼。无法固定版本时重新接收当前 ZIP。已保存文件通过大小、身份记录及 SHA-256 核验后跳过。

## 下载后本地拼接与裁剪

在「下载完成后的操作」选择「保留 ZIP，再本地拼接和裁剪研究区」，随后选择研究包、自然色、NDVI 等输出。软件先完成全部已选完整 ZIP 的下载与校验，再从本地 ZIP 准备原生波段，完成完整拼接，最后从保存的拼接影像裁剪研究区。ZIP、完整拼接和研究区成果分别保留。

原生 DN 根据同包 XML 的 BOA 定标转为反射率，各波段保留自己的缺测范围；SCL、云掩膜、未掩膜备份和像元来源遵循 [研究分析包说明](S2_RESEARCH.md)。本地处理的内部区块只用于限制内存，并非联网分块取片。需要为完整 ZIP、本地原生波段和中间栅格预留空间。

按月模式默认逐月保存全部已选 ZIP；选择本地处理后，每月完成「全部 ZIP → 整月拼接 → 城市裁剪」，只使用该月的实际瓦片采集日期。规则和完整城市边界见 [城市逐月下载说明](CITY_MONTHLY.md)。需要 GEDI 跟随本次 GeoTIFF 时，应选择本地处理并指定生成的参考影像，或使用已有 GeoTIFF。

## 软件更新

点击右上角「检查更新」，再点击「下载并安装」。软件按公开 GitHub 稳定版校验安装包名称、大小和 SHA-256，完成后自动打开 Windows 安装向导，按向导提示更新。无需去文件夹寻找安装包。

系统未能打开安装程序时，任务面板显示「开始安装」，点击可重试；已校验安装包会保留并复用。影像任务运行期间不能开始安装。更新请求使用已有网络代理设置，保持 TLS 校验，不载入影像账号或 GitHub 登录凭据。
