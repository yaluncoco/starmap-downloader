# 官方完整 ZIP 下载

软件默认选择「Sentinel-2 L2A · 官方完整 ZIP（与网页一致）」。画出研究区或导入边界、选择 UTC 日期后检索，勾选需要的精确产品，再点击「下载选中完整 ZIP」。下载使用已保存的 CDSE 账号；检索无需登录。Sentinel Hub Client ID 和 Secret 用于另一条区域裁剪路线。

默认每个产品保存一个同名文件，例如：

    S2A_MSIL2A_20240610T030531_N0510_R075_T50TMK_20240610T081949.SAFE.zip

研究区只筛选相交的产品，ZIP 保存完整源范围。保留全部原始波段、质量与大气图层、产品和瓦片元数据，以及实际产品附带的辅助文件。地图显示几个源产品，就按选择保存几个 ZIP；地图上的内部处理区块不决定 ZIP 数量。

使用 Copernicus Browser 的官方产品编号和整包下载入口。传输显示实际接收字节、速度与预计剩余时间；目录成员体积只是估算，实际 ZIP 长度由下载服务确定。下载完成后检查产品身份、全部 ZIP 文件 CRC 和 SAFE 清单声明的成员长度及散列，记录本地 ZIP SHA-256。目录产品校验值不直接视为动态打包 ZIP 的完整散列；完整性校验也不等于影像科学质量评价。

## 下载方式与并发

「下载方式」有四种选择，普通与按月任务使用同一组设置：

| 方式 | 行为 |
| --- | --- |
| 自动（默认） | 桌面版优先使用 Edge，引擎不可用时使用标准下载；本地网页服务使用标准下载 |
| Edge 浏览器引擎 | 使用 Windows 网络设置，完整文件直接写入磁盘，无需先在网页内存中积累完整 Blob |
| 标准下载 · 系统网络 | 使用现有系统网络和代理设置，支持有可靠源版本记录的前缀续传 |
| 标准下载 · 直连 | 产品下载与产品元数据请求直连官方服务；账号登录仍使用现有系统网络 |

可同时下载 1～4 个不同产品，默认 2 个。单个 ZIP 保持官方整包请求。界面逐产品显示排队、下载、校验与完成，确认窗口列出当前方式和并发数；任务运行时设置锁定。一个产品失败或取消后停止新调度，等待其余活动文件写入停止，已完成且验证通过的产品保留。本地拼接仍等全部所选 ZIP 完成校验。

速度取决于网络、官方服务和账号配额。界面提供 [Copernicus Browser](https://browser.dataspace.copernicus.eu/) 和 [官方配额说明](https://documentation.dataspace.copernicus.eu/Quotas.html) 入口。官方普通账号当前公布最多 4 个连接，达到月流量上限后可能降速；软件不根据速度猜测账号是否达到配额。本机本次 Edge 完整产品约 0.89 MiB/s，系统网络、直连及两产品并发都未明显突破约 1 MiB/s；不要把并发数视为保证的提速倍数。

失败或取消后可以继续原冻结任务，使用原研究区、日期、精确产品、设置和位置。Edge 在本次运行中对浏览器标为可恢复的网络中断尝试原生恢复；关闭软件或取消尚未完成的 Edge 传输后，未完成产品会重新接收。HTTP 跨重启前缀续传要求服务提供强对象版本标识及有效区间；版本或长度变化时拒绝混拼，无法固定版本时重新接收。接收完整而在校验阶段取消的 ZIP 可重新校验，已保存产品经大小和 SHA-256 核验后跳过。切换方式或并发数不会改变内容目录，可复用 1.9.0 已验证 ZIP。

## 下载后本地拼接与裁剪

在「下载完成后的操作」选择「保留 ZIP，再本地拼接和裁剪研究区」，随后选择研究包、自然色、NDVI 等输出。软件先完成全部已选完整 ZIP 的下载与校验，再从本地 ZIP 准备原生波段，完成完整拼接，最后从保存的拼接影像裁剪研究区。ZIP、完整拼接和研究区成果分别保留。

原生 DN 根据同包 XML 的 BOA 定标转为反射率，各波段保留自己的缺测范围；SCL、云掩膜、未掩膜备份和像元来源遵循 [研究分析包说明](S2_RESEARCH.md)。本地处理的内部区块只用于限制内存，并非联网分块取片。需要为完整 ZIP、本地原生波段和中间栅格预留空间。

按月模式先下载全部已选月份的 ZIP，各月共享 1～4 个产品的总并发上限。选择本地处理后，全部月份下载结束再逐月完成「整月拼接 → 城市裁剪」，只使用该月的实际瓦片采集日期。规则和完整城市边界见 [城市逐月下载说明](CITY_MONTHLY.md)。需要 GEDI 跟随本次 GeoTIFF 时，应选择本地处理并指定生成的参考影像，或使用已有 GeoTIFF。

## 软件更新

点击右上角「检查更新」，再点击「下载并安装」。软件按公开 GitHub 稳定版校验安装包名称、大小和 SHA-256，完成后自动打开 Windows 安装向导，按向导提示更新。无需去文件夹寻找安装包。

系统未能打开安装程序时，任务面板显示「开始安装」，点击可重试；已校验安装包会保留并复用。影像任务运行期间不能开始安装。更新请求使用已有网络代理设置，保持 TLS 校验，不载入影像账号或 GitHub 登录凭据。
