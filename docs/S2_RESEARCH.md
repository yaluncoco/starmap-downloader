# Sentinel-2 研究分析包与完整 SAFE

完整城市边界、跨年月份选择和每月一份拼接影像见 [城市逐月下载说明](CITY_MONTHLY.md)。各月仍使用本文的研究包、质量和来源规则。

软件默认保存官方完整 SAFE ZIP；也可选择下载后在本地拼接与裁剪，详见 [完整 ZIP 下载](SAFE_ZIP.md)。选择本地处理后，以及 Sentinel Hub、公开区域与官方 S3 区域路线，默认使用「研究分析包」和「跨日期拼接」。原有自然色、RGB＋近红外、12 波段、NDVI 和自选波段仍可选择。需要逐产品区域输出时，Sentinel Hub 与公开区域路线可改为「时间序列」；完整 ZIP 的本地处理和官方 S3 区域入口提供拼接。

研究分析包保存以下文件，所有栅格使用同一研究区、坐标系、范围与像元网格：

| 文件 | 内容与用途 |
|---|---|
| `mosaic_research_…tif` 或逐产品研究 TIFF | 主分析影像：10 个 BOA 反射率波段，应用当前云掩膜 |
| `….unmasked.tif` | 未应用云掩膜的同源 10 波段反射率；保留负反射率及各波段自己的缺测范围 |
| `….scl.tif` | 原 SCL 分类值 0–11，UInt8；255 表示研究区或来源覆盖之外，区别于真实类别 0 |
| `….source.tif` | UInt16 来源索引；正整数对应来源表，0 表示没有光谱数据 |
| `….sources.json` | 来源索引、产品号、采集时间、像元使用数量、匹配方法、定标、处理规则与来源资料 |
| `….starmap.json` | 主影像及配套文件的大小、SHA-256 和有效像元统计，供重复下载时核验 |

下载以产品或一份区域拼接为单位排队，当前数据及配套文件完整性校验通过后才处理下一个。研究分析包保存上表可直接分析的 TIFF、来源与校验记录，拼接时还包含分配范围。完整 SAFE 的入口和原有模式继续可选。

波段顺序是 **B02、B03、B04、B08、B05、B06、B07、B8A、B11、B12**。光谱 TIFF 为 Float32，单位为无量纲地表反射率，NoData 为 `-9999`。前四个波段原生为 10 米，后六个为 20 米；使用最近邻对齐，输出 10 米不会增加 20 米波段的空间细节。备份经过研究区裁剪、网格对齐和反射率转换。

开启云掩膜时，主影像仅保留 SCL **2、4、5、6、7、11**，剔除 0、1、3、8、9、10；**雪类 11 保留**。主影像要求所有选定波段均有数据，备份保留各波段可用值。即使主影像全部为 NoData，只要存在未掩膜光谱，研究包仍保存。关闭云掩膜也保存 SCL 和来源图。

## 地图选择与跨日期拼接

检索列表每行是一个真实源产品。地图默认只显示已选产品的完整覆盖，并按同一卫星、同一次过境合并范围，隐藏内部产品边线；不是生成一个更大的原始产品。可切换全部候选、逐产品影像及 UTC 采集日期；地图筛选不会改变下载选择。检索后自动定位影像全幅，「影像总览」可再次定位，「放大地图」可展开查看。黄色边界是研究区，日期颜色表示真实拍摄日。

点击交叠范围可勾选具体产品及其他日期的补云影像，与列表同步。覆盖面板显示已选产品、过境、瓦片、日期、几何覆盖、交叠和缺口；勾选「查看拼接分配范围」可查看优先分配。精简推荐在按指定优先级寻找覆盖后，清理被其他推荐产品完整覆盖的冗余来源，保留确有独有覆盖的边缘。它按几何覆盖精简，不保证无云；需要更多备用日期时手动加选。同一瓦片的不同日期可能覆盖不同边缘，不能仅按瓦片号去重。

默认云量较低优先，也可选择日期较新或手动排列。每个像元先用较高优先级产品；开启补齐时，仅用已选的后续产品替换云、NoData 或不完整光谱。备份、SCL 和来源图跟随最终来源，十个波段不会分别混用不同产品。关闭补齐时严格采用优先分配范围。分配视图的填色表示几何分配，实际使用日期与像元数以来源图和来源表为准；几何覆盖不代表无云或存在光谱值。

RGB、NDVI 和自选波段拼接也保留 SCL、来源图和来源表，但未掩膜十波段备份只由研究模式提供。拼接目录另存研究区与分配 GeoJSON、下载记录。删除研究区会清除边界、绘制或编辑状态、目录结果、选择和计划。

## 官方 S3 区域拼接

需要同版官方原始像元时，选择 **「Sentinel-2 L2A · 官方 S3 区域拼接（原始像元）」**。检索和下载均需要已保存或本次载入的 CDSE S3 Access Key、Secret Key；不使用 Sentinel Hub 处理额度。

检索先扩大候选区 0.2°，再下载产品和瓦片 XML，以官方产品边界、瓦片实际采集时间和完整精度云量作最终筛选。本次十包样例中，CDSE 目录对两份 SMJ 产品的边缘范围有偏差；该流程修正了这些案例。候选扩展不能保证找回任意地区目录中完全缺失的产品。

研究模式每个产品下载 **14 个对象**：十个原生 JP2 波段、SCL、`MTD_MSIL2A.xml`、`MTD_TL.xml` 和 `manifest.safe`。选定原件完整传输并解码，核对产品、瓦片、时间、网格、BOA 定标以及清单中 13 个成员的长度与校验值；清单不能校验自身，另外保留其传输和本地摘要记录。反射率采用 `(DN + BOA_ADD_OFFSET) / BOA_QUANTIFICATION_VALUE`，DN 0 的缺测按各波段处理。

原件保存在拼接目录的 **`官方原件缓存`**，首次下载体积较大，计划中显示估算；已有原件重新校验后复用。两份原始 XML 包含产品实际提供的角度与元数据，来源表保留引用及校验证据。它们与选定 JP2 合起来仍不是完整 SAFE；已完成的派生包复用核对其自身全部配套文件，无需保留原件缓存。

## 其他区域来源与完整性

公开路线从所选 Earth Search Collection-1 产品读取，按 STAC 比例与偏移转为 BOA 反射率。Sentinel Hub 使用所选产品白名单，并核对服务返回的来源；`safe_id` 表示完整 SAFE 标识，`mgrs_and_utc` 表示唯一瓦片与采集秒匹配，后者无法确认服务未公开的处理版本。

本次两日期接缝对照发现，Sentinel Hub 在部分官方 JP2 有值的位置返回全零及无数据；改用原 DN 请求也不能恢复。这一入口不能保证覆盖官方完整产品的所有有效像元。要求官方像元覆盖时使用官方 S3；公开路线的本次接缝对照通过，但同样只证明已验证的产品与区域。

发布前逐块解码，核对光谱、SCL、掩膜、来源和网格，并计算每个配套文件 SHA-256。配套文件缺失或改变时不会把主 TIFF 当作完整包跳过。发现旧输出不完整时，移走该组文件及 `.starmap.json` 后重试；软件不会覆盖另存的数据。

中断后可继续原任务。公开源字节区间以强 ETag 和长度固定版本，磁盘缓存核验 SHA-256 后使用；完成的裁剪区块保存全部栅格及来源证据。Sentinel Hub 只重新请求尚未完成的区块；官方 S3 可复用经验证的原件。最终核验光谱、SCL、未掩膜备份及逐像元来源后才标记完成。强版本标识缺失的原始传输会重新接收当前文件；不把本地缓存散列当作提供方的科学质量保证。

公开源将相邻所需页合并为最多 4 MiB 的请求；大请求传输中断后改用较小区间，在原重试预算内继续。小区间仍使用原强 ETag，完整接收并校验范围后才保存；源版本改变或错误区间不会通过缩小请求被接受。

## 完整 SAFE

默认「官方完整 ZIP」来源，以及区域选项中的 **「下载完整 Sentinel-2 SAFE」**，都使用与 Copernicus Browser 相同的整包入口。快捷入口保留研究区、日期与输出位置，重新检索精确产品。完整 ZIP 保留全部 12 个 L2A 光谱波段、SCL、云雪质量文件、AOT、WVP、产品与瓦片 XML、太阳和观测角度资料，以及产品实际附带的其他原始成员。详见 [完整 ZIP 下载](SAFE_ZIP.md)。

研究派生栅格不包含 B01、B09、独立云概率、AOT/WVP 或角度栅格。官方 S3 缓存附带两份 XML，但完整 SAFE 的其他成员仍需另存。需要与手动完整包保持相同信息范围时，应保留同版完整 SAFE。派生 TIFF 的文件字节不等于源 JP2。
