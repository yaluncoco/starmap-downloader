## 完整 ZIP 与处理顺序

主界面默认「Sentinel-2 L2A · 官方完整 ZIP」，普通和按月模式均每产品保存一个同名 `.SAFE.zip`。研究区用于选择相交产品，整包保留全部源波段、质量层及元数据。使用 Copernicus Browser 的官方产品 UUID 和 `download.dataspace.copernicus.eu/odata/v1/Products(UUID)/$value` 整包入口。

可选择「保留 ZIP，再本地拼接和裁剪研究区」。全部已选 ZIP 完成产品身份、CRC 和 SAFE 清单校验后，才从本地原件准备原生波段，保存完整拼接影像，再从该文件裁剪完整研究区。ZIP、完整拼接及区域成果分别保留。按月任务只使用该月产品，当前月三阶段完成后进入下一月。下载显示实际字节、速度和预计剩余时间，本地处理区块用于控制内存。

ZIP 校验覆盖全部文件 CRC、SAFE 清单声明的成员长度与散列，并记录本地整包 SHA-256。目录产品的成员体积为 ZIP 大小估算；目录产品摘要不能直接作为动态整包 ZIP 的官方散列。文件完整性检查与影像科学质量评价的范围分别记录。

## 原生 JP2 与安装版完整本地处理

实网 ZIP 使用真实 `JP2OpenJPEG` 解码。在三个 256 × 256 原生网格窗口，对十个研究波段及 SCL 与直接从 ZIP 提取的独立原件逐值比较，全部相等。原生 BOA offset 为 -1000、quantification 为 10000，瓦片 XML 采集时间为 `2024-06-10T03:16:50.553457Z`。本地提取和窗口核验期间 **零 HTTP 请求**；选定成员另按同包 SAFE 清单核验。

实际安装的 **1.9.0 EXE** 完成官方检索、ZIP-only 复用与「全部 ZIP → 完整本地拼接 → 研究区裁剪」。验证配置预置了刚实传且已核验的同一 ZIP，下载阶段通过大小与 SHA-256 复核后复用；安装版该项计为缓存复用与完整本地处理实测。

完整本地分析使用单 B04、60 m、1832 × 1832 网格。独立解码原始 JP2，核对全部 **3,356,224** 个网格位置的反射率、主影像掩膜、SCL 和像元来源，逐值相同。裁剪的全部 **80** 个网格位置等于已保存完整拼接的对齐窗口再应用原研究区掩膜；SCL 和来源亦相同。单波段全幅与十波段窗口分别限定本次实测覆盖范围，多景与取消由受控回归覆盖。
