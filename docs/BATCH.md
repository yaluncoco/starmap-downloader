# 同区域多来源联合下载 · 1.5.0

选择一个主入口，在「附带下载」勾选其他来源，只需设置一次研究区和 UTC 起止日期。例如主数据为 Sentinel-2 L2A，同时下载 GEDI 高度或生物量，也可附带 Sentinel-1、MODIS、DEM 等现有数据。

## Sentinel-2 + GEDI 操作

1. 首次启动或没有已保存账号时，软件自动打开顶部「登录账号」。按需要载入 Earthdata User Token，或使用 Earthdata 用户名密码；其他平台也在此分别连接。登录成功后默认加密保存，下次打开自动恢复。所有登录控件只位于此窗口，左侧只选择数据。
2. 选择「Sentinel-2 L2A · 公开区域裁剪」作为主来源，在「附带下载」勾选 NASA GEDI，选择产品版本和所需字段，例如 L2A 的 `rh95`、`rh98` 或 L4A 的 `agbd`。主功能也可以换成其他入口。
3. 在地图画矩形或多边形，或导入面状 SHP / GeoJSON。输入坐标也可设置区域。需要另存边界时，点击地图上的「导出边界」。
4. 填写共同的 UTC 起止日期，点击「检索主数据及附带数据」。在「主数据」和「GEDI」等页签中分别勾选结果。地图虚线边框随当前页签切换，点击交叠处可选具体产品，与该页签列表同步。附带原始文件路线可为每个产品分别勾选波段或成员文件。
5. GEDI 的「跟随本次主 GeoTIFF」会先完成明确选中的主文件，再读取它的实际坐标系、仿射变换、行列数和范围。Sentinel-2 默认跨日期拼接时，参考为唯一主分析 TIFF；时间序列多景或多个原始 TIFF 可在「GEDI 跟随的主 GeoTIFF」选择具体文件。勾选「在足迹表格中附带参考影像像元值」可同时采样该影像。
6. 也可为 GEDI 选择「同研究区的 UTM 网格」，或指定已有 GeoTIFF。只保存 GEDI 原始文件时不需要网格参考。
7. 确认所有来源的选中项、时间规则、输出位置和参考，再开始下载。开始前会检查本次所有必需账号；缺失凭据时不会先下载其他来源。

Sentinel-2 区域光学默认使用 [研究分析包](S2_RESEARCH.md)及跨日期拼接。主来源和附带来源分别保存云量／日期／手动优先级与选块顺序；计划显示产品数、选中日期、几何覆盖和区域输出份数。官方 S3 区域入口检索与下载均需 S3 密钥，每个研究产品另保留 14 个原件缓存。GEDI 跟随它的主分析 TIFF，未掩膜、SCL 和来源图作为配套文件保存。

## 时间与空间含义

| 数据 | 共同日期的作用 | 区域的作用 |
| --- | --- | --- |
| Sentinel-2 跨日期区域拼接 | 所选产品可来自不同采集日期；实际像元日期见来源图 | 仅已选产品拼接与补齐，统一为一份区域影像 |
| 单次光学时间序列、雷达、条带及 GEDI 足迹 | 按同一 UTC 日期范围检索；GEDI 派生结果再逐足迹筛选日期 | 裁剪路线按区域导出；原始路线只选择相交产品 |
| Sentinel-2 季度镶嵌、ESA 年度产品、GEDI L3/L4B | 与完整季度、年度或汇总期重叠即匹配 | 保留完整周期的产品含义 |
| MODIS 合成产品 | 沿用各产品 UTC 标称日规则，真实观测窗口另列记录 | 选择完整 MODLAND 瓦片 |
| DEM、CDSE 中的静态 DEM / S2GLC | 不按采集日期筛选，不表示所选日的观测 | 仅共用研究区 |

共用日期不保证卫星在同一时刻过境，也不保证该区域和时段存在每个来源的数据。GEDI 约 25 米足迹是离散观测，未观测的像元保留 NoData；对齐不插值补齐轨道间隙，也不会提高汇总栅格的观测分辨率。

## 输出与重试

共同目录为 `联合下载_<计划摘要>`，包含 `研究区.shp/.shx/.dbf/.prj/.cpg`、`联合下载记录_<编号>.json` 和各来源子目录。联合记录保存共同边界、日期、选中项、计划、来源状态和已完成文件；各来源继续保留原有校验与来源记录。

各来源、各产品按队列依次下载，当前产品完整性校验后再处理下一个。跟随主文件的 GEDI 使用所选参考。一个来源失败不会删除其他来源或已校验完成的文件；「无匹配」「未选择」「参考未生成」「部分完成」分别显示。取消时停止后续工作，保留已校验的原件、源字节区间、SEN3 成员及裁剪区块；未完成影像不作为最终文件发布。原始数据保持来源格式，区域结果保留可直接分析的影像与配套文件。

失败、部分完成和取消后可点击「重试下载／继续下载」。软件重启后在「未完成的下载」继续，使用原任务的边界、日期、产品、参数、参考与保存位置；当前界面选择变化不会改变原任务。账号不写入任务定义，重新连接后使用当前凭据。原始文件及所有配套文件均经完整性核验后跳过；源版本与保存进度不一致时停止，损坏缓存只重新获取受影响的部分。已有最终文件损坏或参数不匹配时需移出对应文件及校验记录。参考失败时不会自动使用另一影像。

## 登录与验证

Earthdata、Sentinel Hub OAuth、CDSE OData 和 CDSE S3 是独立平台凭据。所有登录控件始终位于同一账号窗口，切换来源不会清除其他平台的保存或连接状态。保存、恢复与删除规则见 [账号说明](ACCOUNTS.md)。公开数据仍沿用原本的免个人账号路线。

本地自动测试覆盖实际文件传输处理、GeoTIFF / HDF5 解码、主网格对齐、足迹采样和浏览器流程，使用模拟上游内容。真实 NASA CMR 目录可免登录验证；受保护 GEDI 文件需要用户本人在本机界面完成 Earthdata 认证及数据中心授权。两种验证在记录中分别注明，目录检索不等于认证下载。

应用使用提供的 `globe-orbit.svg`；ICO 包含多个尺寸，应用于 Windows 窗口、EXE、安装程序和快捷方式，SVG 同时用于界面品牌和 favicon。
