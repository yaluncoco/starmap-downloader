# 1.6.0 验证记录

验收日期：2026-11-23（北京时间）。Windows x64、Python 3.12、实际 Microsoft Edge / WebView2。源码、安装包和本机安装版为 1.6.0。测试使用隔离配置与独立输出目录；当前 CDSE S3 密钥只在一个隔离验证会话使用，原账号文件不改写，凭据、影像和机器日志不提交仓库。上版记录见 [1.5.1 验证记录](VALIDATION-1.5.1.md)。

## 下载与恢复的变化

- 原始产品按来源、产品依次下载和校验，保存来源原始格式；区域分析保存 GeoTIFF 及质量、备份和来源配套文件。SLC 区间和 SEN3 成员继续采用有上限的内部并发。
- 失败、部分完成或取消后，可从下载面板继续；重启后显示未完成任务。任务保存原研究区、精确产品、参数和输出目录，恢复时使用当前账号。任务定义有 SHA-256 校验，不写入密码、令牌或临时签名地址。
- 原件续传绑定强 ETag、总长和已记录前缀 SHA-256；未记录尾部重新获取。错误 Range、版本或授权响应不会覆盖可信进度；成品校验失败不发布。接收已完成而解码被取消时，可直接继续验证。
- 公开 COG 保存固定版本的字节区间缓存；区域输出与拼接保存完整区块、数组规格和来源证据。损坏缓存重新获取，源版本不一致停止。输出完成后复核全部配套文件，再清理临时缓存。
- GEDI 复用原件续传；SLC 保存并复核区间进度；SEN3 保留已验证成员，核对清单和完整成员集合后发布。联合下载按来源执行，跟随主影像的 GEDI 使用实际完成的所选 GeoTIFF。
- 数据传输共用有上限的重试与可取消退避，减少重复的嵌套重试，区分暂时错误、限流、授权与 TLS 错误。修复 Windows 本地请求体未读完便关闭连接，导致校验错误响应丢失的问题。

默认 Sentinel-2 研究分析包继续保存 B02、B03、B04、B08、B05、B06、B07、B8A、B11、B12，以及 SCL、十波段未掩膜备份和逐像元来源。其他模式与完整 SAFE 入口保留，窗口和首页品牌名称为「星图影像下载器」。

## 最终回归

最终 **616 项通过，零失败、零错误、零跳过**，耗时 **372.10 秒**。覆盖原件、GEDI、公开裁剪、Sentinel Hub、拼接、SLC、SEN3、MODIS、WorldCover、联合下载、恢复 API、实际 Edge 页面和更新通道。

故障测试包括独立本地 HTTP 的断线与错误区间响应、前缀损坏、源版本变化、认证失效、共享重试预算、取消等待、缓存损坏、重启后恢复原选择、迟到任务状态及网页重试。GEDI 测试用真实 HDF5 结构和确定的源摘要，验证被拒绝的续传不会删除有效前缀，下一次从精确位置继续并校验成品。这些故障测试不冒充提供方实网传输。

源码编译、修改文件的空白检查通过。验收脚本另修正了云量参数遗漏、公开计划可省略认证字段、历史本地版本号假设和 Windows 扩展路径误判；修正后实传验收重新完成。

## 实网恢复与其他路线

公开 Sentinel-2 恢复验收完成第一个完整区块后取消，取消响应耗时 **0.781 秒**。保留 **48 个源字节区间、50,331,648 字节（48 MiB）**，未发布未完成研究 TIFF。重启后修改当前研究区和输出偏好，再从保存任务恢复，实际输出仍使用原产品、原区域和原目录。

恢复阶段复用 **1 个完整区块、48 个缓存区间**。这个样例所需剩余源数据已在缓存中，恢复阶段 **0 次网络请求、0 个重新接收字节**；其余区块从已校验字节生成。完成后进行上表全部像元对照，再次下载核验所有配套文件并跳过，未完成任务列表为空。该项为真实提供方传输后的用户取消与重启测试；提供方断线及错误响应由本地故障测试覆盖。

安装版另在 **1280 × 720 的实际 Edge 页面**补测两个继续入口。真实公开下载接收 **8 MiB** 后，通过页面取消并实际点击面板「继续下载」；接收累计 **16 MiB** 后再次取消，关闭验证服务并冷启动。随后在页面改为 DEM 来源、不同研究区及不同输出目录，再实际点击未完成任务中的「继续下载」，仍恢复原 Sentinel-2 研究包。两次取消的响应分别为 **0.734 秒、0.578 秒**。冷启动恢复复用 **16 个缓存区间**，另执行 **32 次 Range、新接收 32 MiB**；两个按钮均在窗口内可见且可点击，页面脚本错误为零。
