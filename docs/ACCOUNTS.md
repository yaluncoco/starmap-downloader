# 登录账号与自动保存 · 1.4.1

所有账号输入、注册和凭据获取入口都在右上角「登录账号」窗口。左侧只保留数据来源、日期、参数、研究区域和保存位置。

首次启动会自动打开登录窗口。按需要选择平台并填写完整信息，连接成功后默认保存，不需要另行勾选「记住」。下次启动并行恢复各平台已保存的账号，慢平台不会延后其他平台，状态查询不等待网络认证；没有已保存账号或账号恢复失败时，仍会自动打开登录窗口。公开数据可点击「暂不登录，选择数据」继续使用，下一次未登录启动时仍会弹窗。

| 平台 | 保存的信息 | 下次启动 |
| --- | --- | --- |
| Sentinel Hub | 同一客户端的 Client ID、Client Secret | 重新获取访问令牌 |
| NASA Earthdata | 用户名和密码，或所选 User Token | 用保存的账号重新连接，或载入令牌 |
| CDSE OData | 邮箱和密码，或临时令牌；账号会话的刷新令牌 | 优先恢复会话，并保存轮换后的刷新令牌 |
| CDSE S3 | Access Key、Secret Key | 自动载入；数据访问权限仍在下载时验证 |

平台账号彼此独立，登录一个平台不会替代其他平台的登录。目录可检索、令牌已载入和数据中心已授权是不同状态。NASA 首次使用仍可能要求在 Earthdata Search 授权 LP DAAC / ORNL DAAC。

账号文件位于当前用户的 `%LOCALAPPDATA%\CopernicusDownloader\accounts.v1.dpapi`，由 Windows DPAPI 加密并绑定当前 Windows 用户。普通 `preferences.json` 只保存输出位置和非秘密客户端标识；密码、令牌和密钥不会写入普通配置、日志、下载记录或接口返回，也不会回填为网页中的明文密码。

已保存的账号需要重新验证时，可以留空密码或 Secret 沿用保存的信息；输入新的内容会更新保存。更换用户名或客户端标识时，需要填写匹配的新密码或 Secret。一次性两步验证码不保存；若 CDSE 会话过期且需要两步验证，窗口会提示补填当前验证码，可以沿用已保存的密码。

每个平台的「退出并删除」会同时断开当前连接并删除该平台的保存信息，保留其他平台。「清除全部登录信息」会断开所有账号并删除本机保存。下载或认证正在进行时，这些操作暂不可用。关闭程序保留账号信息；升级保留本机配置、账号和已下载文件。卸载只删除软件文件，账号信息可在卸载前通过登录窗口清除。

Windows 桌面和开始菜单快捷方式明确引用随软件安装的 `globe-orbit.ico`；图标由指定 `globe-orbit.svg` 生成，包含 16–256 像素的九个尺寸。新安装默认创建桌面快捷方式。
