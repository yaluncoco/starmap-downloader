# 1.7.1 验证记录

验收日期：2026-11-24（北京时间）。Windows x64、Python 3.12、实际 Edge / WebView2。源码、最终安装包和本机安装版为 1.7.1；使用隔离配置与原验证任务的输出，真实账号及旧影像保持不变。历史范围见 [1.7.0 验证记录](VALIDATION-1.7.0.md)。验证目录、影像、账号及机器日志不提交 GitHub。

## 下载与界面修复

- 公开 Sentinel-2 和 DEM 区域读取使用 256 KiB 缓存页，将当前所需的相邻区间合并为最多 4 MiB；继续读取原生像元，不用 overview 替代。RTC 保留原区间策略。
- 公开拼接最多四路读取不同波段，每路拥有独立 HTTP 会话，并在同一固定线程上打开、读取、关闭 Rasterio 自定义 opener。月份与产品依次处理，最多保留两个打开的产品组。该并行改动用于公开拼接，不表示所有来源采用四路。
- 原 1 MiB 缓存页只有在同版本、完整长度和全页 SHA-256 通过后才能截取复用；损坏重取、版本变化拒绝。任一路读取失败停止其他读取，用户取消不会发布半成品。固定重试上限、SCL、NoData、备份和来源规则保持一致。
- 统一 HTTP、公开区间、通用原件、Sentinel Hub 与 SLC 的 SSL 分类。只有明确的 TLS 提前断开按原预算重试；证书错误及未知 TLS 错误立即停止并分别提示，不回显可能含凭据的诊断，证书校验保持开启。较大公开区间重试可降级，原件及 SLC 仍固定版本和已核验前缀。
- 底图最多同时接收三个瓦片，为本地账号和任务请求保留连接；切换底图或移走瓦片取消旧请求。受控慢底图在修复前阻塞登录，修复后可在瓦片仍停顿时完成登录，切换后旧队列不再发送。
- 后台规划时可以选片、切换月份与排序；选择变化取消旧计划，并按最新选择重新规划。按钮恢复时同时保留首尾排序限制，下载期间仍锁定选择。真实浏览器验证了取消旧计划、重排后的新请求及重复排序。

## 最终回归

**670 项通过，零失败、零错误、零跳过**；JUnit 汇总 **404.18 秒**。覆盖城市、跨年逐月、SHP、冻结任务、取消与恢复、真实浏览器、原件、SLC、SEN3、MODIS、WorldCover、GEDI、Sentinel Hub、公开裁剪、拼接、联合下载及更新。

新增真实 TCP 检查覆盖四路请求、独立会话、读取器同线程生命周期、响应头和内容停顿时取消、坏区间停止其他读取、旧页复用、缓存损坏和源版本变化；像元与续传缓存逐项核对。浏览器检查包含故意停顿的地图源和可取消的后台计划。这些注入故障不作为提供方故障证据。

新增真实 TLS ClientHello 后对端提前关闭的回归，确认其 Requests / urllib3 包装属于明确的 EOF，并只使用公开区间原有的三次预算；五条路线的证书和未知 SSL 错误均不重试、不泄露原文。另核对原件剩余前缀、SLC 原有四次预算、Process 原有三次预算、响应关闭、取消退避及部分字节不进入成品。

首次完整回归曾有四个账号／排序浏览器失败；修复底图连接竞争和按钮状态后完整重跑通过。原失败证据保留，不以单独重试通过代替修复。

## 续作耗时与慢因

1.7.0 安装版原任务取得部分数据后主动取消，保存原任务、版本、网格和可信缓存，用于受控优化和接续。首个 1.7.1 候选续作在最后观测到 556/1260 区块后，因被统一显示为证书错误的 SSLError 返回部分完成，没有发布半成品。原异常被旧处理隐藏，无法确认本次究竟是证书校验还是 TLS 提前断开；后续八次同版对象请求在开启证书校验的情况下正常返回，也不能追溯证明原故障原因。

修正分类并重跑回归、重建和安装后，最终安装版从**最新失败任务**恢复，保留原月、产品、网格与参数，**2762.67 秒**完成，复用 **555 个输出区块、0 个单独源请求区块**。该耗时只对应最后续作，不冒充全新缓存的整城时间。失败与主动取消阶段分别保留：

| 阶段 | 状态 | 记录耗时（秒） | 新接收字节 | Range 请求 |
|---|---|---:|---:|---:|
| installed-1.7.0-baseline | cancelled | 189.19 | 123,787,097 | 85 |
| installed-1.7.1-failed-stage1 | partial | 1651.27 | 842,539,180 | 1,569 |
| installed-1.7.1-tls-fixed-stage2 | completed | 2762.67 | 1,306,280,510 | 2,365 |

各实传阶段记录耗时合计约 **4603.13 秒**，不包含阶段间的代码修改、回归与安装等待；基线时间取采样的活动区间，不包含未采样端点，其余分别取任务生命周期和最终续作计时。不是从全新缓存连续下载的速度基准。

最终续作记录：**2,365 次 Range、新接收 1,306,280,510 字节、5,958 次磁盘页命中、59 次区间失败、40 次大区间降级**。失败计数包括已恢复的尝试，不表示成品缺失；完整性检查后才发布。基线、失败与成功续作累计新接收 **2,272,606,787 字节**。

来源打开阶段合计 **10.14 秒**，读取阶段 **1564.33 秒**；其中包括 HTTP 等待和本地栅格处理，不能直接等同纯网络时间。观测进程平均约 **0.42 个 CPU 核心**，工作集峰值约 **1970.8 MiB**。原串行读取、1 MiB 页额外传输、源连接重试，以及整城 10 m 十波段加备份的数据量共同影响耗时。研究包未压缩约 26.6 GB，实际文件合计 **7,006,963,756 字节**。1260 是内部处理区块数，含边界外区块及交叠处理，不能按进度线性推算剩余时间。

再次执行同一月份，整组核验后跳过，耗时 **6.406 秒**；研究包与 SHP 的 **11 个文件时间不变**。

## 独立原生像元与地图

官方 CDSE 目录按完整 SAFE 名称精确查询，本次选择的七个源均有同版产品记录，保留产品 UUID、内容日期、长度及提供方目录摘要。该项确认产品身份，没有下载十月的官方完整包，也不以目录摘要替代实际字节校验。

使用独立、固定 HEAD ETag 的内存 HTTP 读取器，不复用软件缓存或软件重投影代码，直接按输出像元中心读取每个实际使用源的原生 COG。核对 **7 个实际来源、482 个位置、4,820 个波段值**，最大反射率误差 **6.84738159507e-08**，SCL、NoData 和主影像质量筛选一致。该抽查是公开原生 COG 对照；十月没有宣称为官方完整 SAFE 对照。

全像元核查发现的 **2,134 个部分光谱像元**另逐个追溯：以独立、固定版本的原生 COG 检查这些位置的全部缺测波段，缺测值与原生 NoData 相同，各缺测波段计数为 **{"B02": 1500, "B04": 230, "B03": 311, "B08": 93}**。备份保留其余可用波段，主影像正确剔除不完整光谱；没有插值补造缺测值。此项同样属于公开原生源核对。

原生抽查和缺测追溯的首次独立会话各遇到远端提前关闭连接，日志及失败记录保留；中断检查未计为通过。最终对同一固定 ETag 数据重新完整核查，独立读取器对连接中断和适用 HTTP 临时错误最多三次请求，对证书及未知 TLS 错误立即停止。最终原生抽查记录 1 次传输重试，缺测追溯记录 0 次；没有复用程序缓存或降低证书校验。两项独立检查禁用环境代理，分别耗时 986.89 和 2702.92 秒，包含本地扫描与参考源读取，另列为验收时间，不计入影像下载阶段用时。

官方同版 SAFE 的历史对照保留在 [1.7.0 验证记录](VALIDATION-1.7.0.md)：十个只读官方包的小区／接缝，以及四月真实城市输出的六个同版官方源。没有把历史四月对照宣称为本轮十月全部来源的官方逐像元对照。

最终实际安装版在 Edge 验证月度规划、恢复和两种底图；标准 **18 张**、卫星 **18 张**可见瓦片全部加载，页面错误为零，月份及整城轮廓截图保留。
