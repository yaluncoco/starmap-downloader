## 下载顺序与恢复

普通日期范围的 Sentinel Hub Process API 拼接与时间序列，先下载、校验并缓存全部所需源区块，再关闭 HTTP 连接，只读本地缓存组装成果。拼接在下载阶段用临时区块数组检查云和缺测，仅决定必要补齐请求的范围；正式拼接影像在离线阶段写出。两阶段共用像元选择逻辑，保持科学网格、产品优先级、云规则和精确请求范围。缓存缺失或改变会停止本地处理；继续任务时重新核验下载。

按月整景任务先收齐全部已选月份，再逐月本地拼接、裁剪。完整 SAFE ZIP 跨月填补空闲下载位置，各月共享最多 1～4 个产品的总并发上限，默认 2，不按月份叠乘。原件、配套文件和记录在等待期间核对 SHA-256；失败月份独立记录。取消停止新调度并等待活动文件写入停止，已验证原件和区块保留。

真实 1.10.0 标签源码与新版的四种规划对照通过：普通 ZIP、普通本地研究、月度 ZIP、月度本地研究的内容目录均可复用；普通执行指纹保持相同，月度执行指纹随下载顺序变化。旧任务保留产品、参数与目录；含整景设置的任务采用全部月份下载先行，早期未含整景设置的任务沿原区域读取方式继续。
