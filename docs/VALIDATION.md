# 1.7.0 验证记录

验收日期：2026-11-24（北京时间）。Windows x64、Python 3.12、实际 Microsoft Edge / WebView2。最终源码、安装包和本机安装版均为 1.7.0。验证使用隔离配置与新输出目录，原账号及旧影像保持不变；机器日志、加密账号文件和下载影像不提交 GitHub。上版证据见 [1.6.0 验证记录](VALIDATION-1.6.0.md)。

## 完整城市与每月输出

- 内置 371 个行政范围、34 个省级目录，使用固定版本的公开行政边界，GCJ-02 转为 WGS84。逐个核验完整面、范围与成员 SHA-256；下载边界不简化，北京等直辖市包括下辖县区。完整边界另存为 SHP。
- Sentinel-2 公开区域、Sentinel Hub 和官方 S3 区域三条路线提供跨年起止月份。每月独立检索、选择、规划，按月依次生成一份主拼接 TIFF；默认云量较低优先，可调整产品与顺序，不混入相邻月份。
- 默认十研究波段、SCL、未掩膜备份与逐像元来源继续保留。根目录保存完整城市 SHP 及各月记录；无匹配、未选择、无有效像元、失败和完成分别记录。
- 检索、后台规划、下载与继续任务支持取消；未完成入口可移除并保留输出和缓存。恢复冻结原月份、产品、参数与边界，使用当前账号。地图外任务栏保持可操作。

## 最终回归与传输故障

最终 **644 项通过，零失败、零错误、零跳过**，JUnit 汇总耗时 **407.92 秒**。覆盖完整城市、跨年与闰月、空月和未选月、单月失败、城市 SHP、冻结计划、恢复、取消、真实 Edge、地图，以及原件、GEDI、公开裁剪、Sentinel Hub、拼接、SLC、SEN3、MODIS、WorldCover、联合下载和更新通道。

取消回归使用独立本地 HTTP，分别在响应头和流式内容停顿时取消，验证调用能够返回且后台接收线程不写下载文件。覆盖规划锁被占用时的取消、迟到回调、规划重排、页签切换、消息提示遮挡按钮和地图初始化失败后其他功能继续可用。

公开 COG 将当前读取需要的相邻页合并，最多 4 MiB；逐页缓存格式兼容旧版。新增真实 TCP 故障回归：大响应截断或 HTTP 503 后改用小区间，内容、强 ETag 和缓存一致；源版本变化被拒绝；连续失败仍遵守原重试上限。不使用平均 overview 替代原生像元，继续最近邻对齐。失败记录保留传输及缓存复用统计。这些故障注入不作为提供方真实故障的证据。

## 官方原生像元对照

本机十个官方 SAFE ZIP（`D:\Datasets\2604`）保持只读。本次读取元数据并完成十个独立小区和一个跨日期接缝，共 **11 组原生像元对照、312,650 个波段值，最大反射率误差 0**；SCL、NoData、边界掩膜与来源一致。该项直接读取本地原件，不属于重新下载或重新核验十包全部成员。

实际 4 月城市输出另以六个精确同版官方产品直接读取 JP2 像元中心，抽查 **441 个位置、4,410 个波段值**，最大反射率误差 **1.1920928955078125e-07**，SCL 与 NoData 一致，含被当前质量规则剔除的位置。该误差在 Float32 转换精度范围。实际输出的另外三个源产品没有对应的本地官方包，未将六产品抽查宣称为全部来源的官方逐像元对照。

全部城市像元核验发现 4 月 **15 个部分光谱像元**：B02 缺测 7 个，B03 和 B04 各缺测 4 个。逐个直接核对同版官方 JP2，缺测范围与 SCL 相同，其余反射率一致；备份保留可用波段，主影像将不完整光谱设为 NoData。修正验收脚本中“有来源就必须有全部波段”的错误假设，改为核对各波段有效性、来源与任一光谱数据的对应关系，以及主影像对完整光谱的要求；没有插值补造缺测值或删除备份信息。

5 月另有 **1 个 B02 缺测像元**。通过独立、固定 ETag 的 HTTP 读取器重新读取该位置的公开原生 COG，未复用程序缓存：B02 的原生 DN 为 0（NoData），其余九个波段反射率与 SCL 均与输出一致，主影像正确剔除不完整光谱。该项核对公开原生源，不声明为官方 SAFE 对照。
