实际网络接缝为 `117.060,39.30,117.075,39.32`，4 月 11 日 SMJ 与 4 月 8 日 SNJ，云量优先。完整性检查比较主影像、十波段备份、SCL、逐像元来源以及实际两日期贡献，并复核重复下载缓存。

**来源限制：** Sentinel Hub 在该接缝的部分位置返回全零、SCL／dataMask 无数据，而同版官方 JP2 十个波段均有有效值；来源图与官方参考有 4,374 个像元差异。直接请求原 DN 仍无法恢复，不通过放宽参考或掩膜隐藏失败。现有 Process 入口保留，要求官方有效像元覆盖时使用新增官方 S3 区域拼接。公开 Earth Search 的实际接缝像元对照已经通过；其对照按该目录提供的产品范围分配，而官方 S3 按原始 XML 范围分配，两者来源像元数量不同。验收结果按路线分别记录，不将公开目录范围冒充官方 XML 范围。
