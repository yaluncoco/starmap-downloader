# 1.4.1 验证记录

验收日期：2026-11-21（北京时间）。Windows x64，Python 3.12，实际 Microsoft Edge / WebView2。

## 源码与界面

全套测试 **532 项通过，零失败、零跳过**，包括 13 项真实 Edge 页面测试。新增回归复现并修复 OAuth / OData 登录、刷新令牌时阻塞状态查询，以及慢平台延后其他保存账号恢复的问题。测试同时覆盖账号保存失败、原子替换失败时保留旧文件、损坏配置恢复和状态接口不复制或返回秘密信息。

下载回归覆盖共同研究区与 UTC 日期、GEDI 主影像网格对齐和足迹像元采样、多来源认证检查、部分失败、取消、长路径、损坏文件、来源及网格验证。Python 编译和 JavaScript 语法检查通过，10 个验证脚本均可按文档中的直接命令加载。

## 已打包程序与安装

打包程序及安装后的原生窗口标题均为「星图影像下载器」。未保存账号的连续两次冷启动打开「登录账号」；全部登录控件位于该窗口，左侧只保留数据设置。模拟 Earthdata / S3 凭据经过实际 Windows DPAPI 加密，冷启动自动恢复；单平台删除及全部清除通过。四平台完整信息保存、OAuth / OData 网络认证及刷新会话轮换使用模拟服务验证。

隔离安装从 **1.4.0 升级至 1.4.1**，升级前后的输出设置、用户文件和加密账号文件保持一致；卸载保留用户文件和当时的账号状态，删除临时程序、注册项及快捷方式。本机实际升级也保留了原配置，安装 EXE 与验收 EXE 哈希一致。

桌面与开始菜单明确引用指定地球 ICO。Windows shell 返回的实际 40×40 图标与源 ICO 按相同方式渲染并添加系统快捷方式箭头后的 RGB 像素完全一致。安装包、内置图标、账号说明等资源与源码一致。

## 真实公开数据

使用同一 SHP 和 **2024-06-10 UTC** 检索北京研究区：Sentinel-2 一景、GEDI L3 五项、DEM 一项。缺 Earthdata 连接时联合下载在创建输出前被阻止；随后只勾选公开数据，真实下载 Sentinel-2 B04 与 GLO-30 DSM，通过独立像元、坐标系及本地 SHA-256 核对。

| 输出 | 网格 | EPSG | 有效像元 | 中位数 |
| --- | --- | --- | --- | --- |
| Sentinel-2 B04 地表反射率 | 44 × 57，10 m | 32650 | 2337 | 0.1162 |
| Copernicus DEM DSM | 15 × 20，30 m | 32650 | 252 | 49.5627 m |

没有使用用户真实账号，也没有执行受保护 NASA 文件的认证实传。目录检索、模拟认证和公开数据实传分别记录；这些检查不能证明任意日期、地区或外部服务均可用。
