## 月度处理顺序

新月度任务先下载本月全部已选整景，逐景核对完整性及身份；全部通过后，只读取本地文件生成整月拼接；整月文件保存并校验后，再按原始完整研究区裁剪。当前月完成后才进入下个月。

公开路线保存选定波段及 SCL 的完整原生 COG、三份产品／瓦片元数据与源 SHA-256。官方 S3 路线保留完整 JP2、SCL、XML 与 SAFE 清单；Sentinel Hub 先导出每景光谱、质量与来源。选定原件和整景导出不等于完整 SAFE。整景、整月影像及最终裁剪分别保存。

整月中间影像保留原始反射率和质量／来源。最终成果按研究包、RGB、RGBNIR、十二波段、自选波段或 NDVI 输出；派生转换只在最终阶段执行。整月拼接和城市裁剪使用同一 UTM 网格；裁剪读取已保存文件的对齐窗口，不再次重采样。旧冻结月度任务按原流程继续，新任务使用独立的计划标识。

## 独立原件像元对照

使用 [check_monthly_scene_reference.py](../scripts/check_monthly_scene_reference.py)，从已保存且再次匹配源 SHA-256 的完整 COG 直接读取原生像元索引。该脚本不调用应用读取器、重投影、区块缓存或 HTTP。

核对 **7 个实际使用来源、2,622 个位置、26,220 个波段值**，包括全部 **2,127 个部分光谱位置**。SCL、原生 NoData 和主影像质量掩膜相符；最大反射率绝对误差 **5.96046447754e-08**，阈值为 2e-7。

这是本次公开 COG 原件的独立像元对照；本次没有下载十月官方完整 SAFE 进行字节比较。官方 JP2 负反射率及部分波段缺测由受控案例验证；历史官方 SAFE 实测范围保留在旧版验证记录中。

## 安装版接续、复用与耗时

整景阶段由源码恢复任务执行。原件全部通过后，在阶段交接处主动取消并确认停止，保留原任务、精确产品、月份、网格、边界及文件。安装版从该冻结任务冷启动恢复，复核复用原件，实际完成本地整月拼接和城市裁剪。交接为受控验证，取消日志不代表原件失败。

| 阶段 | 记录耗时（秒） |
|---|---:|
| 下载全部整景（源码恢复任务） | 3567.85 |
| 下载全部整景（安装版） | 15.54 |
| 本地整月拼接（安装版） | 5760.27 |
| 裁剪完整研究区（安装版） | 2158.07 |

安装版恢复任务计时 **7939.27 秒**；前表阶段时间不包含阶段间打包、安装和人工核查等待。该任务有恢复、内部连接重试和一次人为交接，不作为全新缓存连续整城速度基准。下载完整整景的数据量通常更大，总耗时仍受网络、原件体积和磁盘影响。计划列出原件、中间成果、最终成果及临时空间。

三阶段任务完成后，原验收脚本和第一次续接的执行会话先后以 143 退出，全城验收报告尚未写完；后续后台启动包装会话也返回 143，原因均未确定。独立原件像元对照的通过报告完整保存。独立 Windows 后台进程从原已保存成果完成全城文件核验，已通过的逐块报告直接保留；后续复用和浏览器核验在 Windows Start-Process 创建的进程中执行，基线和任务编号先写入文件，结果独立保留。会话退出和后台续接均保存本地证据，不计入上表的数据处理耗时；未重新生成原件、整月影像或城市成果。

首次复用已跳过全部城市成果，研究包和 SHP 的文件时间保持不变，但验收脚本随后因要求整份处理记录摘要不变而触发断言。重复任务会更新记录中的复核起止时间和复用状态，该旧条件与实际记录方式不符。修订条件后，另起 Windows 后台进程重新执行复用核验：比较原计划、产品身份、网格、成果路径、来源日期及数据／文件校验记录的时间和长度。处理记录的前后快照及原断言均保留；原实测三阶段时间保存在已完成任务快照和本次全城验收报告中。

修订条件后的首个后台验收进程在结果汇总前停止，未记录 Python 异常，安装服务已完成该次三阶段复核。后续改用上述 Start-Process 启动方式重新完成剩余验收；启动包装器等待超时，但实际 Windows 核验进程继续运行。此类验收进程退出原因尚未确定，均在本地保存观察记录。

安装版独立规划检查约 **1.062 秒**，这只计规划，不计下载。修订验收条件后再次执行同一月份，经核验后跳过 **1** 份城市成果，耗时 **324.250 秒**；研究包和 SHP 的 **11** 个文件时间不变。扩展核对全部 **213** 个原件、整月／城市成果、文件校验记录及 SHP 的时间与长度不变；原件、中间影像和城市成果均核验后跳过。
