# 1.10.0 验证记录

验收日期：2026-11-25（北京时间）。Windows x64、Python 3.12、真实 Edge / WebView2。当前源码、正式安装包及 `D:\apps\StarmapDownloader` 安装版均为 1.10.0。前版结果保留在 [1.9.0 验证记录](VALIDATION-1.9.0.md)；本轮真实证据保存在本地 `verification/release-1.10.0/` 与 `verification/browser-alignment/`，账号、配置、影像和截图不提交 GitHub。

## 官网实际流程与新版行为

已在真实 Copernicus Browser 登录、检索固定产品并点击产品详情的 Download 按钮，捕获同一官方 UUID 的 `GET /odata/v1/Products(UUID)/$value`，资源类型为 XHR，认证放在 Bearer 请求头。该次大响应主动中止，只证明真实按钮发出的请求。另核对官方开源仓库 `eu-cdse/copernicus-browser` 的 OData 与下载 hook：网页接收完整 Blob 后保存原名 `.SAFE.zip`。

桌面版使用同一官方完整产品入口和文件名，通过 WebView2 下载操作直接落盘。自动模式优先使用 Edge，引擎不可用时使用标准下载；可选择 Edge、标准系统网络或直连。标准直连的产品请求不使用系统代理，账号登录仍沿用现有系统网络。保持正常 TLS 验证，重定向和恢复请求限定同一已核对的完整产品。

完整 ZIP 支持同时下载 1～4 个不同产品，默认 2 个。普通 ZIP、按月 ZIP 及下载后本地处理均传播并冻结这些选项；每产品独立校验，全部已选 ZIP 通过后才离线拼接与裁剪。界面显示产品队列，确认窗口显示方式与并发数。错误或取消停止新调度并等待活动文件写入结束，已验证产品保留。

覆盖普通／按月与 ZIP／本地研究四种组合、独立 HTTP 会话、最大产品并发、失败停止调度、取消等待文件写入、版本固定的双产品跨重启续传、错误清单拒绝保存、完整传输重新校验、界面队列和运行时设置锁定。实际原生事件适配器在受控网络中断事件后从同一文件恢复，恢复请求使用更新后的授权；恢复期间取消不继续写入。拒绝向无关资源发送账号请求头。Edge 原生恢复只适用于当前运行中浏览器标记为可恢复的操作；取消或关闭未完成的 Edge 传输后会重新接收该产品，HTTP 跨重启续传仍要求强对象版本和有效区间。

从真实 `v1.9.0` 标签导出隔离源码，使用同一真实产品分别运行两版规划。普通 ZIP、普通本地研究、按月 ZIP、按月本地研究四种模式的内容目录均相同，新版执行指纹随方式和并发数变化。月份内部的内容身份也匹配；旧版目录兼容由两版实际输出对照证明。
